## iOSSH について

iOSSH は iPhone・iPad 用の SSH ターミナルアプリです。iOSSH 独自のアカウント登録は不要です。保存したホスト、SSH の資格情報、ターミナルの内容を開発者へアップロードするサービスは組み込まれていません。利用者が選んだサーバーへ接続し、各機能を利用する際には、以下のシステム機能や第三者サービスを使用します。

## 端末内で保存・処理する情報

| 情報 | 用途と保存先 |
| --- | --- |
| 保存済みホスト | 再接続のため、ホスト名または IP アドレス、表示名、ポート、SSH ユーザー名、認証方式、端末種別、作成日時、アプリが生成したレコード識別子をアプリ内のローカルデータベースへ保存します。 |
| 保存済み資格情報 | 保存を選んだパスワード、秘密鍵、秘密鍵のパスフレーズは iOS の Keychain に保存します。ホストのデータベースとは分離し、現在登録されている Face ID または Touch ID による認証をアクセス条件としています。iCloud キーチェーンで同期せず、別の端末へ移行しない設定です。接続のために入力した資格情報はメモリ上でも処理します。 |
| 信頼済みサーバー鍵 | サーバーのホスト鍵を承認すると、そのホスト名、ポート、鍵のアルゴリズム、公開鍵を端末内へ保存し、同じサーバーの識別と鍵の変更検出に使います。 |
| ターミナルの内容 | 入出力、スクロール履歴、端末タイトル、受信した端末画像をメモリ上で処理します。ターミナルの記録をファイルには保存しません。切断済みタブにも出力が残る場合があり、タブを隠したり画面をロックしたりしても消去されません。 |
| Tailscale の取り込み結果 | ショートカットから受け取ったホスト名・IP アドレス、そこから作成した表示名、取り込み状態やエラーメッセージを、確認用にメモリ上で保持します。ホストのデータベースへ追加するのは、利用者が選択して保存したホストだけです。 |
| フォント | 「ファイル」で選択したフォントを、フォント名とライブラリ識別子とともにアプリ内へコピーします。同梱フォントと取り込んだフォントの描画は端末内で行います。 |
| 設定 | フォントの選択、文字サイズ、配色テーマをアプリのローカル設定へ保存します。 |

Face ID と Touch ID の処理は iOS が行います。iOSSH が受け取るのは認証結果であり、顔や指紋のデータではありません。登録した生体認証情報の変更や端末パスコードの解除により、保存済み資格情報を利用できなくなる場合があります。

## SSH 接続と接続先サーバー

接続すると、選択した SSH サーバーに、接続元のネットワークアドレス、SSH ユーザー名、認証のやり取り、端末設定、貼り付けたテキストを含む送信した入力が渡ります。アプリはサーバーからターミナルの出力を受信します。ホスト名の解決には端末に設定されたネットワークと DNS のサービスを使用し、Tailscale を使用する場合もあります。

SSH はセッションの通信を暗号化します。パスワード認証では、暗号化されたセッション内で選択したサーバーへパスワードを送ります。秘密鍵認証では端末内で署名し、認証のやり取りには公開鍵と署名を送ります。秘密鍵やそのパスフレーズ自体は送りません。

サーバー側のログ、シェル履歴、ファイル、その先への情報送信は、サーバー運営者とそこで実行するプログラムが管理します。iOSSH で切断したりホストを削除したりしても、接続先に保存された情報は削除されません。

## Tailscale・ショートカット・ウェブサイト

Tailscale の機能は、別途設定した Tailscale アプリとアカウントを使用します。iOSSH は Tailscale の API トークンを要求せず、Tailscale アカウントのパスワードも保存しません。

**Fetch Devices** を選ぶと、Apple の「ショートカット」アプリを開き、**Import Tailscale Hosts** を実行します。同梱ショートカットは Tailscale の **Find Devices** アクションを使い、端末のホスト名または IP アドレスを確認用に iOSSH へ渡します。この間、Tailscale とショートカットが端末の取得結果を処理します。同梱ショートカットのファイルを保存・共有する場合、書き出すのは処理の定義であり、端末一覧や資格情報は含まれません。

Tailscale SSH では、既存の Tailscale 接続を利用してアクセスが確認されます。サーバーがウェブでの承認を要求した場合、アプリはそのメッセージを表示します。サインイン操作を選ぶと、システムのブラウザー画面で Tailscale の HTTPS ページを開きます。そのウェブ認証は Tailscale と、必要に応じて利用する認証プロバイダーが処理します。ドキュメントのリンクを開いた場合も、リンク先のウェブサイトと通信します。

これらのサービスには、それぞれのプライバシーの取り扱いが適用されます。[Tailscale のプライバシーポリシー](https://tailscale.com/privacy-policy)と [Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/en-ww/)を参照してください。サーバーや tailnet の管理者が、別途ログやアクセスの方針を定めている場合もあります。

## クリップボード・ファイル・システム機能

コピー操作では、選択したターミナルのテキストをシステムのクリップボードへ入れます。貼り付け操作を要求したときにクリップボードのテキストを読み取り、選択中のセッションへ送ります。クリップボードの内容を開発者へ自動送信する機能はありません。Apple のユニバーサルクリップボードなどによる共有は、システムの設定に従います。

フォントの取り込みでは、利用者が選んだファイルを読み取ります。クラウドストレージなどの「ファイル」プロバイダーが、その選択に伴ってファイルをダウンロードする場合があります。iOSSH で取り込んだフォントを削除しても、削除するのはアプリ内のコピーであり、元の保存先のファイルではありません。

アプリ独自の iCloud・CloudKit 同期機能はありません。ホスト設定、信頼済みサーバー鍵、設定、取り込んだフォントなどの通常のアプリデータは、iOS とバックアップの設定に従って端末のバックアップに含まれる場合があります。システムのバックアップや「ファイル」プロバイダーには、それぞれの保持・削除の操作があります。

## 解析と診断情報

アプリには、広告、アプリをまたぐ追跡、開発者向けの利用状況解析 SDK、クラッシュレポートの自動アップロード機能はありません。外部のテレメトリーサービスも設定していません。iOS やシステムのフレームワークが、Apple の方針と端末の解析情報共有設定に従って診断情報を作成する場合があります。これは iOSSH 独自のレポート送信サービスとは別のものです。

App Store のアプリについて、Apple が利用者の共有設定に従い、クラッシュ情報や利用統計を開発者へ提供する場合があります。iOS の **「設定」→「プライバシーとセキュリティ」→「解析と改善」** にある **「App デベロッパと共有」** で管理できます。[Apple の「App 解析とプライバシー」](https://www.apple.com/uk/legal/privacy/data/en/app-analytics/)を参照してください。

## 保持期間と利用者による管理

- ホスト一覧から保存済みホストを削除すると、そのデータベースのレコードと関連する保存済み Keychain 資格情報を削除します。開いているセッションは終了しないため、接続を止めて保持中の端末内容を破棄するには、そのセッションも別途閉じてください。
- 信頼済みサーバー鍵は別に保存しており、ホストの削除後も残ります。現時点のアプリには、ホスト鍵を個別に削除する操作はありません。
- 取り込んだフォントは **Settings** で削除できます。外観の設定もここで変更できます。
- 端末のバッファと未保存の取り込み結果は、永続的なセッション履歴や取り込み履歴としては保存せず、メモリ上に保持します。それらを所有するセッション・状態が解放されたとき、またはアプリのプロセスが終了したときに破棄されます。接続先のサーバーは独自の履歴を保持する場合があります。
- iOS でアプリを削除すると、アプリの保存領域内のデータが削除されます。「App を取り除く」操作では書類とデータが保持されます。アンインストールによる Keychain 資格情報の消去には依存せず、消したい資格情報に対応する保存済みホストを先に削除してください。バックアップ、クリップボードのコピー、書き出したショートカット、他のアプリやサーバーが保持する情報は別に管理されます。
- Tailscale の取り込み機能の利用をやめ、ショートカットを「ショートカット」アプリから削除できます。Tailscale の権限やアカウント情報は Tailscale で、ローカルネットワークや Face ID などのアプリの権限は iOS の「設定」で管理してください。
