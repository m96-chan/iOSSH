# UDEV Gothic NF 2.2.0

These four TrueType files are unmodified copies from the upstream release:

https://github.com/yuru7/udev-gothic/releases/tag/v2.2.0

Archive: https://github.com/yuru7/udev-gothic/releases/download/v2.2.0/UDEVGothic_NF_v2.2.0.zip

The `UDEVGothicNF` variant has a halfwidth/fullwidth ratio of 1:2, includes
Nerd Fonts symbols, and does not enable programming ligatures. The `35`
(3:5 widths) and `LG` (ligature) variants are not bundled. All four authentic
styles are included so bold and italic prompts retain the same font family.

UDEV Gothic combines BIZ UD Gothic, JetBrains Mono, and Nerd Fonts. The
upstream OFL 1.1 license and each source-font license are preserved in this
directory and included in the application resource bundle.

Source notices: https://github.com/yuru7/udev-gothic/tree/v2.2.0/source
